## Один обязательный шаг — SQL
Dashboard → SQL Editor → вставьте **supabase/rpc.sql** → Run

Без этого не работают: ключи активации, админ-панель, скачивание мода.

Или на ПК (нужен пароль БД в secrets.local.env):
  node tools/apply-rpc.mjs

## Edge Function (для мода Minecraft)
